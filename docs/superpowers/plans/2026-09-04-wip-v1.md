# WIP V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a public-safe durable crash-recovery protocol and validator so long-running agentic work can resume after failed messages without blindly repeating external effects.

**Architecture:** WIP stores immutable workspace identity plus append-only checkpoints and operation transitions, with small mutable HEAD/RESUME projections. Periodic checkpoints protect work-state continuity; write-ahead operation events protect ambiguous external effects. A standard-library validator checks invariants locally and in GitHub Actions.

**Tech Stack:** Markdown, JSON/JSON Schema, Python 3 standard library, `unittest`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-04-wip-v1-design.md`

## Global Constraints

- Default periodic cadence is exactly 5 substantive non-WIP tool calls.
- WIP bookkeeping calls do not increment the cadence counter.
- Verified external writes checkpoint immediately.
- Non-idempotent effects require an append-only `PREPARED` event before execution and target inspection before any retry after interruption.
- Historical checkpoint and operation-event records are append-only.
- `HEAD.json`, `RESUME.md`, and `registry/workspaces.json` are mutable projections.
- Public repository payload classification is `PUBLIC_SAFE` only.
- WIP continuity never grants external effect authority.
- Lifecycle has no `DONE` value.
- Runtime tool has no third-party Python dependencies.

Tests must assert that the future validator:

```python
from tools.wip import validate_workspace

# valid example yields no errors
self.assertEqual(validate_workspace(valid_path), [])

# HEAD/checkpoint disagreement is rejected
self.assertTrue(any("latest_checkpoint" in e for e in validate_workspace(bad_path)))

# RESUME marker disagreement is rejected
self.assertTrue(any("RESUME" in e for e in validate_workspace(bad_path)))

# unresolved PREPARED operation is surfaced as a recovery warning, not silently ignored
result = inspect_workspace(path)
self.assertIn("op-000001", result["unresolved_operations"])

# DONE lifecycle is rejected
self.assertTrue(any("DONE" in e for e in validate_workspace(bad_path)))
```
